# HS Automation — Updates

Public update channel for HS Automation (Hamza Saeed's video automation platform).

- `manifest.json` — latest version, release notes, download URL, SHA-256.
- GitHub Releases — update zips (full releases and delta patches).

The dashboard checks `manifest.json` daily. If the version is newer than the installed one, it offers Update Now (backup first, rollback on failure).

Never committed here: API keys, tokens, user data, or credentials of any kind.
